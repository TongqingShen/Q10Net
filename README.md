# Q₁₀Net

## Overview

Q₁₀Net provides the supporting dataset and neural network analysis code for the study:

**“Compound Effects of Warming and Wetting Enhance Soil Respiration on the Earth’s Third Pole”**

## Description

The code is used to analyze the controlling factors of soil respiration temperature sensitivity (Q₁₀) and predict its spatiotemporal dynamics under future climate scenarios using a neural network model.

The dataset contains compiled in situ Q₁₀ observations from the Tibetan Plateau, associated environmental variables, and source references.

## Repository contents

- `Q10Net.py` — Neural network modeling and interpretability analysis code
- `Q10_Dataset.xlsx` — Compiled in situ Q₁₀ observations and associated environmental variables
