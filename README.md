# Q₁₀Net: Code and Data for “Compound Effects of Warming and Wetting Enhance Soil Respiration on the Earth’s Third Pole”

This repository contains the **supporting code and dataset** for the study:

**“Compound Effects of Warming and Wetting Enhance Soil Respiration on the Earth’s Third Pole”**

---

## 📌 Description

- The provided **code** is used to **explain the controlling factors of soil respiration temperature sensitivity (Q₁₀)** and to **predict its spatiotemporal dynamics under future climate scenarios** using a neural network model.
- The **dataset** includes original field measurements of Q₁₀ and associated environmental drivers, along with source references.

---

## 📁 Contents

- `Q10Net.py` – Python code for Q₁₀ modeling and explanation
- `Q10_Dataset.xlsx` – Original observed dataset with environmental variables and Q₁₀ values
