# Q₁₀Net

## Overview

Q₁₀Net provides the supporting dataset and neural network analysis code for the published study:

**“Compound Effects of Warming and Wetting Enhance Soil Respiration on the Earth’s Third Pole”**

published in *Global Biogeochemical Cycles* (2026).

## Description

Q₁₀Net is designed to analyze the environmental controls on the temperature sensitivity of soil respiration (Q₁₀) and to predict its spatiotemporal dynamics across the Tibetan Plateau under future climate scenarios using a neural network model.

The dataset contains compiled in situ Q₁₀ observations from the Tibetan Plateau, associated environmental variables, and source references. The accompanying Python code implements the neural network modeling and interpretability analyses used in the study.

## Repository Contents

* `Q10Net.py` — Neural network modeling and interpretability analysis code
* `Q10_Dataset.xlsx` — Compiled in situ soil respiration Q₁₀ observations and associated environmental variables
